# Login Project

## Overview.

This project is a simple and modern login application built with React and TypeScript.

The goal of this project is to practise building React components, working with forms, styling interfaces and testing components.

The application features a clean and responsive design with a dark background, gradient colours and a modern login card.

## Features

- Modern and responsive login interface.
- Clean and simple user interface.
- Custom CSS styling.
- Welcome page design.
- React Router for navigation.
- Component testing with Vitest and React Testing Library.

## Technologies Used

- React
- TypeScript
- CSS3
- React Router DOM
- Vitest
- React Testing Library
- JavaScript (ES6+)

## Design

The application uses:

- Dark background with gradient effects.
- Modern typography using DM Sans and Outfit.
- Rounded cards and buttons.
- Interactive input fields.
- Responsive layout for smaller screens.

## Testing

The project uses Vitest and React Testing Library to test React components.

The current test checks that the login page renders correctly and displays the Login heading.

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
